# Security Playbooks

## Data Breach
1. Detect unusual access or data exfiltration.
2. Contain affected systems (disable accounts, block IPs).
3. Notify compliance officer and begin IRP steps.
4. Preserve logs and evidence.
5. Notify affected users and authorities as required.

## Ransomware Attack
1. Isolate infected machines from the network.
2. Do NOT pay ransom; preserve evidence.
3. Restore from clean backups.
4. Notify compliance officer and authorities.
5. Review and update backup and patching policies.

## Unauthorized Access
1. Disable compromised accounts immediately.
2. Review access logs for scope of breach.
3. Change all relevant passwords and keys.
4. Notify compliance officer and affected users.
5. Conduct post-incident review and update access controls.
