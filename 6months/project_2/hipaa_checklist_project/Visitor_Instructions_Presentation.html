🛠️ Common Issues & Solutions

Quick Fixes

❌ "Cannot connect to server"

Solution: Ensure both backend (port 8000) and frontend (port 3000) are running

❌ "Login failed"

Solution: Use demo credentials: admin / admin123

❌ "Page not loading"

Solution: Clear browser cache and cookies

Advanced Troubleshooting

# Check system health python security_verification_final.py # Test API connectivity python test_backend_api.py # Run comprehensive tests python comprehensive_testing_suite.py

📁 Check Logs

  • Backend: backend/logs/django.log
  • Browser: F12 → Console tab
