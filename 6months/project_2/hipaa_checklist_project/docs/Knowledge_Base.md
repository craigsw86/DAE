## Policies and Standards

- [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) — Industry standard for risk management and controls.
- [HIPAA Security Rule](https://www.hhs.gov/hipaa/for-professionals/security/index.html) — Federal requirements for healthcare data security.
- [ISO/IEC 27001](https://www.iso.org/isoiec-27001-information-security.html) — International standard for information security management.

## Tools and Guides

- [Django Security Documentation](https://docs.djangoproject.com/en/stable/topics/security/) — Secure coding and deployment for Django.
- [OWASP Top Ten](https://owasp.org/www-project-top-ten/) — Most critical web application security risks.
- [pip-audit](https://pypi.org/project/pip-audit/) — Python dependency vulnerability scanner.
- [npm audit](https://docs.npmjs.com/cli/v8/commands/npm-audit) — Node.js dependency vulnerability scanner.

## Incident Response and Forensics

- [SANS Incident Handler's Handbook](https://www.sans.org/white-papers/17401/) — Industry guide for incident response.
- [Log2Timeline Forensics Tool](https://github.com/log2timeline/plaso) — Timeline analysis for digital forensics.
- [Auditd Linux Manual](https://linux.die.net/man/8/auditd) — Linux audit daemon for system monitoring.
