# Figma 1 - Course README

## Course Overview
This course introduces students to Figma, the industry-standard design tool for creating user interfaces, prototypes, and design systems. Students learn fundamental Figma concepts including frames, images, styling, and components. The course emphasizes practical design skills and modern UI/UX design principles.

## Learning Objectives
- Master Figma's core interface and navigation
- Learn to create and organize design frames effectively
- Understand image integration and optimization techniques
- Develop skills in design styling including colors, typography, and shapes
- Create reusable components and design systems
- Build professional UI/UX designs and prototypes

## Course Rubric Requirements

### 1. Frames
- Add at minimum 1 frame to your design
- Demonstrate understanding of Figma's frame system
- Show proper frame organization and hierarchy
- Use appropriate frame types for different design contexts
- Implement responsive design principles with frames
- Document frame usage and design rationale

### 2. Images
- Add at minimum one image to your design
- Demonstrate proper image integration techniques
- Show image optimization and formatting
- Implement appropriate image placement and sizing
- Use images effectively to enhance design communication
- Document image sources and usage rights

### 3. Styling
- Incorporate styling into your design using colors, text, font styles, and shapes
- Demonstrate color theory and palette selection
- Show typography hierarchy and font selection
- Implement shape design and geometric elements
- Create cohesive visual design language
- Document styling decisions and design system

### 4. Components
- Create at minimum one component using a grouping of elements
- These components can have a selection of layers or a grouping of objects
- Demonstrate component creation and organization
- Show component reusability and consistency
- Implement component variants and states
- Document component library and usage guidelines
