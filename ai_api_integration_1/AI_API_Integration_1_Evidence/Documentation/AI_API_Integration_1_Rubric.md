# AI API Integration 1 – Project Rubric

This rubric outlines the requirements for API integration demonstrating RESTful API utilization, data formatting, request/response structuring, and implementation of both open and secured APIs. Each criterion must be met at an advanced level for full credit.

---

## Grading Scale
- **1:** Complete
- **0:** Incomplete

---

## Criteria

### 1. RESTful API Method Utilization
- Use of at least two different RESTful API requests to fetch or send data
- Demonstrate proper HTTP methods (GET, POST, PUT, DELETE, PATCH)
- Show evidence of different API endpoints being utilized
- Document the specific API methods used and their purposes

| Criterion | Complete (1) | Incomplete (0) |
|-----------|:-----------:|:--------------:|
| RESTful API Method Utilization |          |            |

---

### 2. Format and Display API Data
- Pre-formatted data using at least one HTTPS method
- Demonstrate proper data parsing and formatting
- Show user-friendly display of API response data
- Include error handling for malformed or missing data

| Criterion | Complete (1) | Incomplete (0) |
|-----------|:-----------:|:--------------:|
| Format and Display API Data |          |            |

---

### 3. Structuring API Requests and Responses
- Structured API Request and response using HTTPS methods, endpoints/URL, request body, header and status code upon request
- Demonstrate proper request structure with headers, body, and authentication
- Show proper response handling including status codes
- Document API endpoints, request/response formats, and error handling

| Criterion | Complete (1) | Incomplete (0) |
|-----------|:-----------:|:--------------:|
| Structuring API Requests and Responses |          |            |

---

### 4. Implement Open or Secured APIs
- Formatted user-friendly data using public API or private API
- Demonstrate integration with at least one public API
- Show implementation of API authentication (API keys, OAuth, etc.)
- Provide user-friendly interface for API data interaction
