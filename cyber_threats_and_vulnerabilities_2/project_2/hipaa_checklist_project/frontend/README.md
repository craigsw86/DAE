# Frontend Setup for HIPAA Checklist

## Overview
This directory contains the React.js frontend for the HIPAA Checklist Web Application, built with Create React App and Material-UI for responsive design.

## Setup Instructions
1. **Install Node.js**:
   - Ensure Node.js 16+ is installed.
2. **Install Dependencies**:
   bash
   cd frontend
   npm install


Run Development Server:npm start


Access at http://localhost:3000.

## SQL Schema Documentation
- **regulationupdate**: id (PK, integer), title (varchar(255)), description (text), source_url (varchar, nullable), created_at (datetime), updated_at (datetime)
- **checklistitem**: id (PK, integer), user_id (FK to auth_user), regulation_update_id (FK to regulationupdate), completed (boolean, default=False), notes (encrypted varchar(500), nullable), last_updated (datetime)
- **auditlog_logentry**: Auto-generated by django-auditlog for tracking changes.
- **Migrations**: Run `python manage.py makemigrations` and `python manage.py migrate` to apply schema.
